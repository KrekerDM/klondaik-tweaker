Журнал научился перепроверять применённое: Windows после обновлений молча возвращает часть значений, и до этой версии узнать об этом было неоткуда.

## Что появилось

- **Кнопка «перепроверить применённое»** на вкладке «Журнал». Программа проходит по всем незаконченным записям, сверяет каждый твик с текущим состоянием системы и показывает, сколько держится, а сколько слетело.
- **Отметка «слетел»** у записи, значение которой в системе больше не то, что мы записали. Видно сразу в списке, вместе с датой и идентификатором.
- **Кнопка «применить заново»** появляется, когда нашлось слетевшее: применяет обратно ровно те твики, которые не удержались, по одному и с журналом, а не всё подряд.

Проверка ничего не меняет сама — она только читает систему, а решение применять заново принимаете Вы.

Чего она не делает: проверяются только твики из каталога. Записи про службы, задачи планировщика, компоненты Windows и схемы электропитания она пропускает и считает отдельно — для них сверка состояния живёт на их собственных вкладках.

## Проверки

Прогон модулей на чистой Windows 10 — 41/41, самотест — 29/29. Новый шаг проверяет весь путь на настоящем твике из каталога: применить, сломать значение в обход журнала, убедиться, что проверка это поймала, применить заново, убедиться, что твик вернулся. Поймала и вернула.

## Установка

Скачайте `KlondaikTweaker.exe` и запустите от имени администратора. Рядом лежит `KlondaikTweaker.exe.sha256` для проверки файла.

Если у вас 1.2.2, программа предложит обновиться сама.

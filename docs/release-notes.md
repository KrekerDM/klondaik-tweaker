Набор твиков теперь сохраняется в файл и применяется на другой машине одним заходом.

## Что появилось

- **«Сохранить мой набор»** на вкладке «Твики». Программа берёт всё, что применено и не откачено, и пишет в файл, который можно унести на флешке.
- **«Применить из файла»** там же. Файл читается, твики из него применяются обычным путём — по одному, с журналом и с возможностью откатить каждый.
- Если в файле попались твики, которых нет в каталоге этой версии, программа скажет сколько, а не промолчит.

**В файле лежат только идентификаторы твиков**, не значения реестра. Это сделано нарочно: что именно писать в систему, решает каталог внутри программы, а файл не может принести с собой чужую запись в реестр. Чужой или испорченный файл отклоняется с объяснением.

Чего набор не делает: он не переносит состояние служб, задач планировщика, компонентов Windows, схем электропитания и параметров сетевой карты — только твики из каталога. И он не проверяет, что на второй машине та же сборка Windows: версия записана в файл, но решение применять остаётся за Вами.

## Проверки

Прогон модулей на чистой Windows 10 — 42/42, самотест — 29/29. Новый шаг пишет набор в файл, читает обратно и сверяет список твик за твиком, а затем подсовывает чужой JSON и ждёт отказа. Отказ пришёл.

## Установка

Скачайте `KlondaikTweaker.exe` и запустите от имени администратора. Рядом лежит `KlondaikTweaker.exe.sha256` для проверки файла.

Если у вас 1.3.1, программа предложит обновиться сама.

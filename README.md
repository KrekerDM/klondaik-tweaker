# Klondaik Tweaker

Твикер Windows 10/11 с полным журналом изменений и откатом каждого твика по отдельности.
Один переносимый `.exe`, без установки и без зависимостей на машине пользователя.

- 148 твиков в трёх уровнях риска, каждый с описанием на русском и английском
- Мастер подбора: 16 вопросов → персональный набор твиков под конкретную машину
- Отдельная категория «Слабый ПК»: то, что реально ускоряет старое железо
- Инструменты: разовая починка того, что сломали другие твикеры, в один клик
- Очистка, автозагрузка, службы, встроенные приложения, сеть, бенчмарк, каталог софта
- Журнал: перед каждым изменением сохраняется прежнее значение ключа, службы или задачи

## Установка

Скачайте `KlondaikTweaker.exe` из раздела [Releases](../../releases) и запустите
от имени администратора. Установка не нужна, файл один, реестр под себя программа
не правит — настройки и журнал лежат в `%ProgramData%\KlondaikTweaker`.

При первом запуске программа покажет предупреждение о рисках, его нужно принять.

## Обновление

«Настройки» → «Обновление» → «Проверить обновления». Программа спрашивает у
GitHub последний релиз, показывает номер версии и список изменений. По кнопке
«Скачать и установить» файл скачивается, проверяется, программа закрывается,
exe заменяется и запускается заново. Настройки, журнал и история бенчмарка
остаются на месте. Ничего не качается и не устанавливается без нажатия кнопки.

## Требования

**Для пользователя:** Windows 10 1903+ или Windows 11, права администратора, WebView2 Runtime
(предустановлен на Windows 11 и на актуальной Windows 10; иначе программа предложит ссылку).

**Для сборки:** .NET SDK 10, Python 3 (генераторы данных), интернет для восстановления NuGet.

## Сборка

```powershell
.\build.ps1
```

Скрипт пересобирает файлы данных из `tools/`, публикует self-contained single-file сборку
и кладёт `KlondaikTweaker.exe` в `dist/`. Итог — около 54 МБ, всё внутри одного файла.

Отладочный запуск без запроса UAC (интерфейс работает, запись в систему — нет):

```powershell
dotnet publish src\KlondaikTweaker -c Release -o out -p:ApplicationManifest=app.dev.manifest
$env:KLONDAIK_UI_PREVIEW = "1"; .\out\KlondaikTweaker.exe
```

Самопроверка бэкенда без графического интерфейса:

```powershell
.\dist\KlondaikTweaker.exe --selftest report.txt
```

Проверка применения и отката. Берёт десяток твиков, применяет, убеждается что
определение состояния переключилось, откатывает и сверяет состояние системы
побайтово с исходным. Первым идёт синтетический твик на выброшенном ключе
реестра — если механизм отката сломан, это видно сразу. **Только на тестовой
машине или в виртуалке.**

```powershell
.\dist\KlondaikTweaker.exe --selftest-apply report.txt
```

Быстрая проверка одного лишь механизма отката, ничего системного не трогает
и не требует прав администратора:

```powershell
.\dist\KlondaikTweaker.exe --selftest-apply report.txt --canary-only
```

Прогон **всего каталога**: каждый твик применяется, проверяется определение
состояния, откатывается и сверяется побайтово. Твики, которые не подходят системе
или удаляют магазинные пакеты (необратимо), помечаются пропущенными с причиной.

```powershell
.\dist\KlondaikTweaker.exe --selftest-apply report.txt --all
```

Прогон модулей: по-настоящему выполняет очистку, бенчмарк, игровой буст,
все кнопки «Инструментов», точку восстановления и сброс сети. Отчёт пишется
после каждого шага, поэтому обрыв посередине не теряет результат.
**Только в виртуалке.**

```powershell
.\dist\KlondaikTweaker.exe --selftest-modules report.txt
```

## Устройство

| Слой | Где | Что делает |
|---|---|---|
| Хост | `src/KlondaikTweaker/MainForm.cs` | Безрамочное окно WinForms, WebView2, отдача ресурсов из сборки |
| Мост | `src/KlondaikTweaker/Host/Api.cs` | Один роутер `method → object`, обмен через `postMessage` JSON |
| Движок | `Core/Engine/TweakEngine.cs` | Определение состояния, применение, откат, запись в журнал |
| Модули | `Core/Modules/` | Очистка, автозагрузка, службы, приложения, сеть, бенчмарк, буст, каталог |
| Починка | `Core/Modules/Repair.cs` | Разовые действия: службы по умолчанию, Store, поиск, сеть |
| Данные | `Assets/Data/*.json` | Твики, мастер, каталог софта, дефолты служб — вшиты в exe |
| Интерфейс | `Assets/wwwroot/` | HTML, CSS и ES-модули без сборщика, three.js для фона |

Фронтенд не использует npm и сборщики: файлы отдаются прямо из ресурсов сборки по
адресу `https://app.klondaik/`, навигация за пределы этого адреса запрещена.

## Как добавить твик

Твики описываются в `tools/tweaks_a.py` … `tweaks_e.py` и собираются
в `Assets/Data/tweaks.json` генератором:

```python
T("perf.example", "performance", "advanced",
  ("Заголовок", "Что это и зачем", "Чем рискуете"),
  ("Title", "What and why", "What it costs"),
  [R("HKLM", CCS + r"\Control\Example", "Value", "dword", 1, 0)],
  tags=["fps"], src="atlas", restart=True)
```

```powershell
python tools\gen_tweaks.py
```

Генератор проверяет уникальность идентификаторов, корректность веток реестра, типов
значений и непустые описания на обоих языках, и падает с ненулевым кодом на ошибке.

Виды действий: `R` реестр, `RD` удаление значения, `SV` служба, `TK` задача планировщика,
`AX` пакет приложения, `CM` команда, `PS` PowerShell, `HS` домены в hosts.
Поле `req` ограничивает твик системой: `win11`, `ssd`, `laptop`, `desktop`, `nvidia`, `b24h2`,
`lowram`, `highram`, `weakcpu`, `weak`, `strong`. Класс железа определяется автоматически
по объёму памяти, числу потоков и типу системного диска.
Если все цели твика (службы, задачи) на этой системе отсутствуют, он помечается
недоступным, а не «не применён» — переключатель не выглядит сломанным.

Таблица штатных значений запуска для 232 служб лежит в `tools/service_defaults.txt`
и собирается в `Assets/Data/repair.json` через `python tools\gen_repair.py`.

## Права

Не всё в Windows поддаётся администратору: часть ключей реестра, служб и задач
принадлежит `TrustedInstaller`, и обычная запись в них падает с отказом в доступе.
Запись идёт по трём ступеням, каждая следующая включается только если предыдущая
не сработала:

1. Обычная запись от администратора
2. Смена владельца ключа на группу администраторов и выдача полного доступа
3. Выполнение операции под токеном `TrustedInstaller`, с откатом на токен `SYSTEM`

Токен берётся напрямую из процесса службы `TrustedInstaller` через
`OpenProcessToken` и `DuplicateTokenEx` — тот же приём, что в `RunAsTI` у Atlas,
но нативно на C#, без промежуточных скриптов. Нужные привилегии
(`SeTakeOwnership`, `SeRestore`, `SeBackup`, `SeDebug`, `SeImpersonate`)
включаются в токене процесса при старте.

## Безопасность и откат

- Перед применением любого твика прежнее состояние пишется в `%ProgramData%\KlondaikTweaker\journal.json`
- Повторное применение не затирает исходную запись, поэтому откат всегда возвращает первоначальное значение
- Для твиков среднего и высокого риска перед пакетным применением создаётся точка восстановления
- Твики высокого риска требуют отдельного подтверждения со списком того, что именно будет отключено
- Откат доступен поштучно и целиком на вкладке «Журнал»

## Известные ограничения

- `System.Management` (WMI) не работает в single-file сборках .NET 10 — вместо него реестр,
  WinAPI и точечные вызовы PowerShell. Не возвращайте этот пакет в проект.
- `CetCompat` в csproj выключен намеренно. С ним .NET 10 помечает exe как совместимый
  с Intel CET, и на сборках Windows 10 без полной поддержки CET процесс падает до входа
  в `Main` с `0x80131506`. Не включайте обратно без проверки на Windows 10 21H1.
- Твики Защитника не применятся при включённой защите от подделки — программа предупреждает об этом
- Время загрузки системы читается из журнала событий и требует прав администратора
- Температура процессора берётся из ACPI и доступна не на всех материнских платах

## Выпуск новой версии

Версия берётся из `<Version>` в `src/KlondaikTweaker/KlondaikTweaker.csproj`.
Поднимите её, закоммитьте и поставьте тег — GitHub Actions соберёт single-file exe
и приложит его к релизу. Автообновление в программе ищет в релизе ровно файл
`KlondaikTweaker.exe`, имя менять нельзя.

```powershell
git tag v1.1.0
git push origin v1.1.0
```
